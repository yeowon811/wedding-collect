# AI 상담 구조

## 한눈에 보기

```
┌──────────────┐   ┌───────────────────────────── 상담 에이전트 (ConsultAgent) ─────────────────────────────┐
│ ⓪ 내 정보 입력 │   │                                                                                       │
│ 지역·나이·결혼 │──▶│ ① 질문 이해        ② 정보 합치기          ③ 빠진 정보 확인        ④ 데이터 조회      ⑤ 답변 작성 │
│ 단계·예식일·   │   │ (Understander)     내 정보 + 대화 기억    목적별 필수 항목        (ConsultTools)    근거·출처·     │
│ 하객·예산·주택 │   │ 목적·조건·분야 추출  + 이번 질문의 조건    없으면 하나씩 되묻기 ──┐  규칙·DB 값만 사용  다음 질문 버튼 │
└──────────────┘   │                                           ▲                 │                                  │
                    │                                           └─ 사용자 답(버튼/글) ┘                                  │
                    └───────────────────────────────────────────────────────────────────────────────────────┘
```

| 단계 | 파일 | 하는 일 | 지금 | 생성형 AI 연결 후 |
|---|---|---|---|---|
| ⓪ 내 정보 | `features/chat/profile_setup_view.dart`, `data/models/user_profile.dart` | 상담 전에 지역·나이·결혼 단계·예식일·하객·예산·주택 보유 입력. 비워 둬도 됨 | 같음 | 같음 |
| ① 질문 이해 | `features/chat/agent/understanding.dart` | 질문에서 **목적**(정책·예식장·업체·예산·일정·추천)과 **조건**(지역, "20대"→만 20~29세, 하객 수, 예산, 무주택 등), **분야**("신혼생활"→주거) 추출 | 규칙(키워드·정규식) | **LLM이 같은 구조(JSON)로 추출** |
| ② 정보 합치기 | `consult_agent.dart` | 저장된 내 정보 + 이번 대화에서 들은 정보 + 이번 질문의 조건 | 같음 | 같음 |
| ③ 되묻기 | `consult_agent.dart` `_required()` `_ask()` | 목적별 필수 항목 중 모르는 것을 **하나씩** 묻고 선택 버튼 제공. 답을 받으면 원래 질문으로 돌아감 | 같음 | 질문 문장만 LLM이 자연스럽게 다듬을 수 있음 |
| ④ 데이터 조회 | `features/chat/agent/consult_tools.dart` | 예식장 검색, 정책 대상 판정(규칙), 업체 검색, 예산 배분, 다음 할 일 | 같음 | **LLM이 도구로 호출** (숫자는 항상 여기서) |
| ⑤ 답변 | `consult_agent.dart` `_*Answer()` | 결과를 요약·설명, 추천 이유, 확인할 조건, 카드, 출처, 다음 질문 버튼 | 문장 틀 | LLM이 도구 결과만 보고 설명 |

## ③ 목적별로 꼭 필요한 정보

| 목적 | 필요한 정보 (없으면 이 순서로 질문) | 비고 |
|---|---|---|
| 지원 정책 | 지역 → 나이 → 결혼 단계 → (신혼부부면) 혼인 연차 → (주거·전체면) 무주택 여부 | 나이는 "20대"처럼 범위만 알아도 진행, 답변에서 정확한 나이를 요청 |
| 공공예식장 | 지역 → 하객 수 | |
| 업체 추천 | 지역 → 총예산 → (식대·청첩장이면) 하객 수 | |
| 예산 배분 | 총예산 → 하객 수 | |
| 준비 순서 | 예식일 (또는 미정) | |
| 전체 추천 | 지역·나이·결혼 단계·하객·예산 | 내 정보를 입력하고 시작하면 바로 나옴 |

- 모든 질문에 **"잘 모르겠어요"** 버튼이 있어요. 누르면 그 항목 없이 진행하고, 답변에 "알려주시면 더 정확해요"라고 안내해요.
- 되묻는 중에 **다른 질문**을 하면 그 질문으로 넘어가요 (예: 지역을 묻는데 "예산 어떻게 나눠?").
- 대화에서 알게 된 정보는 **이번 대화 동안 기억**하고, "이 정보를 내 정보에 저장" 버튼으로 저장할 수 있어요.

## 대화 예시 (내 정보 없이 시작)

```
사용자: 20대 청년이 신혼생활에 받을 수 있는 정책이 뭐가있어?
  ① 이해: 목적=정책, 나이=만 20~29세, 분야=주거·대출
  ③ 빠진 정보: 지역, 결혼 단계, (혼인 연차), 무주택 여부
상담:   [정보 확인] 지원 정책은 사는 지역에 따라 달라져요. 어느 지역에 살고 계세요?
        (지금까지 알려주신 정보: 만 20~29세)   [서울] [부산] … [잘 모르겠어요]
사용자: [서울]
상담:   혼인신고는 하셨나요?   [아직이에요 (예비부부)] [했어요 (신혼부부)]
사용자: 네 혼인신고 했어요
상담:   혼인신고한 지 얼마나 되셨어요?   [1년 이내] [2~3년] [4~7년] [7년 넘었어요]
사용자: [1년 이내]
상담:   지금 집을 갖고 계신가요?   [무주택이에요] [집이 있어요] [잘 모르겠어요]
사용자: 잘 모르겠어요
상담:   기준: 서울 · 만 20~29세 · 신혼부부(혼인 1년 이내)
        받을 수 있는 주거·대출 정책을 N건 찾았어요. 그중 a건은 조건이 잘 맞고 …
        • 신혼부부 임차보증금 이자지원 사업 — 서울 거주, 혼인 7년 이내 / 확인할 것: 무주택 여부, 소득 기준
        정확한 만 나이를 알려주시면 나이 조건을 더 정확히 판단할 수 있어요.
        [결혼 장려금도 보기] [공공예식장 추천] [이 정보를 내 정보에 저장]
```

## 생성형 AI(LLM) 연결 계획

바꾸는 곳은 **① 질문 이해**와 **⑤ 답변 문장**뿐이고, ②③④는 그대로 둔다. 그래서 LLM이 틀려도 숫자·자격은 바뀌지 않는다.

1. **① 질문 이해 → LLM**: 질문을 보내고 아래 형식으로만 답하게 한다 (`Understander`를 구현한 `LlmUnderstander`).
   ```json
   {"intent": "policy", "topic": "housing", "item": null,
    "facts": {"sido": null, "age": 20, "ageMax": 29, "stage": null, "guests": null, "budget": null, "homeless": null}}
   ```
   - 형식이 틀리거나 응답이 없으면 규칙 기반 `RuleUnderstander`로 대신 처리한다 (장애 대응).
2. **④ 도구 호출**: LLM에 도구 목록을 주고 호출하게 할 수도 있다.
   | 도구 | 입력 | 출력 |
   |---|---|---|
   | `search_venues` | sido, guests | 예식장 ID·이름·정원·요금·예약방식 |
   | `match_policies` | sido, age, ageMax, stage, marriedYears, homeless, topic | 정책 ID·이름·해당 이유·확인할 조건 |
   | `search_vendors` | item, sido, budget, guests | 시연용 업체 ID·가격대·평점 |
   | `budget_plan` | budget | 항목별 금액 |
   | `next_tasks` | weddingDate | 할 일 목록 |
3. **⑤ 답변 문장 → LLM**: 도구 결과(JSON)만 주고 "결과에 없는 숫자·정책·업체는 말하지 말 것, 출처를 붙일 것"으로 설명하게 한다. 카드·출처·버튼은 앱이 직접 붙인다.

## 신뢰성·개인정보 원칙 (심사: AI 오류·불확실성 대응)

- **가격·자격·정원·예약 가능 여부는 도구(DB·규칙) 결과만** 쓴다. AI가 만들어내지 않는다.
- 모르는 값은 지어내지 않고 **되묻거나 "확인 필요"**로 표시한다. 범위로만 아는 나이는 "정확한 나이 확인"으로 남긴다.
- 모든 답변에 **기준(어떤 조건으로 찾았는지)과 출처**를 붙인다.
- 외부 AI로는 **조건(지역·나이대·결혼 단계 등)과 후보 ID·요약만** 보낸다. 이름·연락처·업체 휴대폰 번호는 보내지 않는다.
- API 키는 앱에 넣지 않고 중계 서버에 둔다 (연결 시).
