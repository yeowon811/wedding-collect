### ⑥ Gemini 무료 사용량 초과 (가장 급함)
59턴 중 **질문 이해 21번·답변 문장 13번이 'quota exceeded'로 실패** → 규칙 기반으로 대체됨(그래서 J04 오타·H06 등이 틀림).
날짜 판단이 한 질문에 4번을 동시에 부르고, 질문마다 이해·문장 2번을 부르니 분당 한도를 금방 넘는다. **시연 중 연속 질문에서 같은 일이 생길 수 있음.**

## 해결 방안 (우선순위)

| 순위 | 해결 | 고치는 질문 | 방법 |
|---|---|---|---|
| 1 | **Gemini 호출 줄이기·실패 대비** | ⑥ 전부 | 이해 결과·날짜 판단을 캐시, 날짜 판단을 한 번에 묶어 1회로, 답변 문장 다시 쓰기는 짧은 답에서 생략, 한도 초과면 몇 초 뒤 1번만 재시도. 시연 전 한도 확인(유료 전환 또는 모델·요청 수 조정) |
| 2 | **질문을 '조건 목록 + 질문 종류'로 이해** | ②⑤ | Gemini가 `kind`(추천·비교·계산·특정 장소·일반 지식·자격 확인)와 조건 목록(지역·날짜·예산·인원·제외·주차 등)을 함께 뽑음 → 앱이 조건마다 '규칙으로 거름 / 원문을 Gemini가 판단 / 데이터 없음'으로 처리하고 답에 조건별 결과 표시 |
| 3 | **있는 데이터 연결** | ① | 비용 질문 → wedding_options(공공 표준가·일반 평균가·추가금)로 '공공예식장 총비용 예상'·'항목별 평균' 계산 답변, 주차·피로연·기타 안내 원문 → 날짜 판단과 같은 방식으로 Gemini가 읽고 판단, 특정 예식장 이름 → 그 예식장 상세 답변 |
| 4 | **질문에 답이 있으면 되묻지 않기** | ③ | 되묻기 전에 Gemini 이해 결과의 조건을 먼저 반영("6개월 남았는데" → 예식일 약 6개월 뒤, "혼인신고 안 했는데" → 예비부부). 질문이 묻는 것과 관계없는 필수 정보는 묻지 않고 '알려 주면 더 정확해요'로 |
| 5 | **일반 지식 답변** | ④ | 데이터로 답할 수 없는 질문은 Gemini 일반 안내 + '일반적인 안내이며 앱 데이터가 아님' 표시 + 관련 앱 기능 버튼. 숫자는 쓰지 않거나 출처 있는 것만 |
